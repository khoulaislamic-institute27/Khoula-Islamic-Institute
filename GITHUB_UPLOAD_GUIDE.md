## ❓ GitHub par jo files upload hui hain, wo Vercel par kaise khulen gi?

Vercel par apni website kholne aur connect karne ke 2 aasan tareeqe hain:

### Tareeqa 1: Agar Vercel pehle se GitHub se connected hai
1. Apne browser mein [vercel.com/dashboard](https://vercel.com/) open karein aur login karein.
2. Dashboard par aapko apna project nazar aayega: `khoula-islamic-institute` (ya jo naam aapne rakha tha).
3. Project ke card par click karein.
4. Upar **"Visit"** button hoga ya **Domains** ke neeche aapki live link hogi (maslan `https://khoula-islamic-institute.vercel.app`).
5. Us link par click karein — aapki live website foran khul jayegi!
6. Jab bhi aap GitHub par files upload ya commit karte hain, Vercel **automatically 15-30 seconds ke andar** nayi build tayyar karke website live update kar deta hai.

### Tareeqa 2: Agar Vercel par abhi tak GitHub connect nahi kiya
1. [vercel.com](https://vercel.com/) par jayen aur **Log In** karein -> **"Continue with GitHub"** select karein.
2. Vercel dashboard par blue button **"Add New..."** -> **"Project"** par click karein.
3. Aapki GitHub repositories ki list samne aayegi. Apni repo `khoula-islamic-institute` ke aage **"Import"** button par click karein.
4. "Root Directory" default (./) rehne dein aur neeche **"Deploy"** button daba dein.
5. 20-30 seconds mein Vercel confetti animation ke sath aapko aapki live link de dega!

## 🚀 Nayi Hero Carousel Files ko GitHub & Vercel par kaise bhejein?

Hero Slider aur naye 3 slides ko live dekhne ke liye yeh files GitHub par upload karein:

1. [GitHub.com](https://github.com/) par apni repository open karein.
2. **`Add file`** -> **`Upload files`** par click karein.
3. Apne computer ke folder (`D:\kii\khoula islamic institute kii`) se yeh files drag & drop karein:
   - 📁 **`images/`** folder (khas tor par `slide-nazra.jpg`, `slide-hifz.jpg`, `slide-translation.jpg`, `logo.png`, `favicon.png`)
   - 📄 `index.html`
   - 📄 `styles.css`
   - 📄 `app.js`
4. Commit message likhein: `Add beautiful responsive hero carousel with 3 program slides`.
5. **`Commit changes`** par click karein.
6. Vercel automatic 20 seconds mein aapki website par naya hero carousel live kar dega!
